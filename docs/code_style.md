# 代码规范

本仓库的代码遵循应遵循 ROS2 Code Style，请详细阅读以下资料：

+ [ROS2 Code Style and language versions](https://docs.ros.org/en/humble/The-ROS2-Project/Contributing/Code-Style-Language-Versions.html#id1)
+ [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html)
+ [Python PEP 8](https://peps.python.org/pep-0008/)

提出代码规范旨在提高代码可读性、可维护性及团队协作效率，请大家认真遵守并不断改进。
