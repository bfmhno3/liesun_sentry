## 简介

本仓库由西北农林科技大学猎隼战队开发，主要用于实现哨兵上位机系统的自动化算法，其核心供功能包括：

+ **SLAM 建图**：利用二维激光雷达和下位机数据实时建图；
+ **自动导航**：依托精确定位和路径规划，实现自动导航规划。

## 开发环境

+ **操作系统**：Ubuntu-22.04 LTS
+ **中间件**：ROS2 Humble
+ **其他依赖**：请参照 [INSTALL.md](./INSTALL.md) 进行依赖配置

## 软件架构

软件按照用途分为三个层次：

+ `pc_stm32_comm`：通信层，建立与下位机（STM32）的通信，负责数据交互与命令传递。
+ `lidar_mapping`：建图层，负责处理激光雷达数据并进行建图，为导航层提供环境地图信息。
+ `navigation`：导航层，实现自动导航，包含路径规划、定位修正以及运动控制功能。

各模块之间通过 ROS2 消息进行通信，保证了系统的松耦合设计和易于扩展：

+ [`pc_stm32_comm`](./src/pc_stm32_comm/)
+ [`lidar_mapping`](./src/lidar_mapping/)
+ [`navigation`](./navigation/)
